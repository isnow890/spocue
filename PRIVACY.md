# SpoCue 개인정보처리방침 · Privacy policy

SpoCue는 Windows에서 재생 중인 Spotify 곡의 제목, 아티스트, 앨범명과 커버를 읽어 사용자 PC에 표시합니다. 재생 정보는 메모리에서 처리합니다. 사용자가 복사 기능을 실행하면 곡 정보가 Windows 클립보드에 기록되며, 이후 보관 또는 동기화는 Windows 클립보드 설정을 따릅니다.

단축키, 언어, 알림 등 환경설정은 PC의 사용자별 설정 파일에 저장합니다. 개발자는 계정, 사용 통계 또는 재생 기록을 수집하지 않습니다. Store 버전은 Microsoft Store를 통해 업데이트됩니다. GitHub 배포본에서 업데이트 확인을 사용하면 GitHub에 최신 버전을 요청하며, 이때 GitHub는 IP 주소 등 통상적인 연결 정보를 받습니다. 설정에서 자동 확인을 끌 수 있습니다.

SpoCue reads the current Spotify track title, artist, album and artwork from Windows and displays them locally. Playback information is processed in memory. Using the copy command writes track information to the Windows clipboard, where Windows clipboard history and sync settings apply.

Preferences such as shortcuts, language and notification settings are saved in a local per-user file. The developer collects no accounts, analytics or listening history. The Store edition receives updates via Microsoft Store. The GitHub edition contacts GitHub when checking for a release, exposing ordinary connection details such as the IP address to GitHub. Automatic checks can be disabled in Settings.
