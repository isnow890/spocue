어떤 창에서 작업하든 단축키로 Spotify를 제어하는 Windows 트레이 앱입니다. Spotify 데스크톱 앱이 필요합니다.

• 단축키로 재생/일시정지, 다음 곡, 이전 곡
• 다른 앱 소리는 그대로 두고 Spotify 볼륨만 조절
• 곡이 바뀌면 화면 모서리에 제목, 아티스트, 앨범 커버 알림
• 현재 곡 정보를 클립보드로 복사
• 단축키, 알림 위치, 언어(한국어/영어)를 설정에서 변경

로그인이나 API 키 없이 바로 쓸 수 있습니다. 무료 오픈 소스 앱이며, Spotify AB와 제휴하거나 보증받지 않은 독립 프로젝트입니다.
